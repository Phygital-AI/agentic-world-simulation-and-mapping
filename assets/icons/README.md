# Brand icons

- `github.svg`: GitHub mark from [Primer Octicons](https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg), used under the included MIT license (`LICENSE.octicons.txt`).
- `huggingface.svg`: [Hugging Face official logo](https://huggingface.co/front/assets/huggingface_logo-noborder.svg), with a viewBox added for responsive sizing.

The GitHub icon links to the AWSM repository. The Hugging Face icon is displayed without a link.
