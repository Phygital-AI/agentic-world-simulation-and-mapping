01 / QUESTION

问题与四种方法

M4 在本案例中综合最好，但单场景工程实验不能证明一般性优势。

M1 使用采样 RGB 与无测量尺度的布局；M2 使用 RGB-only ViPE 位姿与 pose-conditioned DA3 深度；M3 使用 ORB-SLAM3 单目惯性位姿与 pose-conditioned DA3 深度；M4 使用 GT 相机位姿与 pose-conditioned DA3 深度，建模时不读取 GT 网格或 GT 深度。

02 / MEASUREMENT

位姿与原生/模型深度

原生深度评估上游链路；模型深度从评测相机向最终冻结 Blender 场景投射射线。

M1 diagnostic limitation. M1 使用由 5 个手工相机关联得到、冻结不变的 GT-assisted Sim(3)；仅作诊断，不表示原生 metric recovery。

03 / EDITABLE ASSETS

可编辑 M1–M4

M4 为 revision 4：74 个 semantic objects、37 个 static AABB colliders、180 台 cameras。独立 reviewer 只审阅了 rev2；rev3/4 修复了已指出的问题，但 rev4 尚无完整独立视觉复审，因此不声称最终视觉通过。

这些展示副本和运行时配准不改变冻结模型；M1 配准仅作诊断。

05 / APPEARANCE

外观

Table 4 使用 5 个固定 640×480 检查视角（0、36、72、108、144）。Table 5 从其余 175 张建模帧中按固定随机种子抽取同一组 100 个视角；它们只相对于固定 5 帧是新的检查视角，仍属于建模 RGB 输入，并非未见输入。全部评测均不裁剪、不遮罩、不逐视角拟合。
